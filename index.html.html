VIDA ASIN Panel — Privacy Policy

Last updated: 18 September 2026 · Publisher: VIDA TRADE LLC

What this extension is

VIDA ASIN Panel is an internal tool for employees of VIDA TRADE LLC. When an employee opens an Amazon product page, it shows a panel with the company's own operational data for that product: stock on hand, expiry dates, orders, advertising performance and a stock-out forecast. It is not a consumer product and is distributed privately.

What data the extension collects

None. The extension does not collect, transmit, sell or share any personal information. It has no analytics, no tracking, no advertising, and no server of its own that receives data.

What the extension reads

  • The ASIN (product identifier) visible in the address of the Amazon product page the user is viewing. This is used only to look up that product in the company's own data, and is not stored or sent anywhere.
  • The company's own Google Sheets and the company's own stock-forecast file. These are read over HTTPS with credentials: 'omit' — no account, cookie or token of the user is used or sent.

What the extension stores

Only on the user's own computer, using the browser's chrome.storage.local:

  • the user's display preferences (attribution window, ACoS thresholds, whether Sponsored Display is included);
  • a short-lived copy of the company data already fetched, so the panel does not re-download it on every page view.

This storage never leaves the device. Uninstalling the extension removes it.

Who the data is shared with

Nobody. The extension sends no data to the publisher or to any third party. The only network requests it makes are to docs.google.com and oos-radar.vercel.app, to read the company's own files; as with any web request, those services see the request itself and the originating IP address, under their own privacy terms.

Permissions and why they are needed

  • storage — to keep the user's settings and the local cache described above.
  • activeTab — so the popup can tell which Amazon tab is open and ask its panel to refresh.
  • alarms — to refresh the stock forecast in the background a few times a day, so opening a product page stays fast.
  • host permission for amazon.com — the panel is drawn on the product page.
  • host permissions for docs.google.com and oos-radar.vercel.app — to read the company's own data files.

Remote code

The extension executes no remote code. All code is contained in the uploaded package.

VIDA ASIN Panel — Politica de confidențialitate

Ultima actualizare: 18 septembrie 2026 · VIDA TRADE LLC

Ce este extensia

VIDA ASIN Panel este o unealtă internă a companiei VIDA TRADE LLC. Când un angajat deschide o pagină de produs Amazon, extensia arată un panou cu datele operaționale ale companiei pentru acel produs: stoc, expirări, comenzi, performanța reclamelor și prognoza de ruptură de stoc. Nu este un produs pentru publicul larg și se distribuie privat.

Ce date colectează

Niciuna. Extensia nu colectează, nu transmite, nu vinde și nu împarte nicio informație personală. Nu are analitice, nu urmărește nimic, nu afișează reclame și nu are niciun server propriu care să primească date.

Ce citește

  • Codul ASIN al produsului din adresa paginii Amazon deschise — folosit doar ca să caute produsul în datele companiei; nu se stochează și nu se trimite nicăieri.
  • Foile Google ale companiei și fișierul cu prognoza de stoc al companiei, prin HTTPS, fără niciun cont, cookie sau jeton al utilizatorului.

Ce păstrează

Doar pe calculatorul utilizatorului: setările lui de afișare și o copie de scurtă durată a datelor deja descărcate, ca panoul să nu le ceară din nou la fiecare pagină. Nu pleacă nicăieri și dispar la dezinstalare.

Cu cine se împart datele

Cu nimeni. Singurele cereri de rețea sunt către docs.google.com și oos-radar.vercel.app, pentru fișierele proprii ale companiei.
